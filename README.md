# PartyKub

Juego local de Rummikub para navegador, con mesa 3D y partidas contra bots.

## Ejecutar

Abre `index.html` en un navegador moderno. El juego no requiere servidor ni
variables de entorno; la mesa 3D carga Three.js desde un CDN y necesita
conexión a Internet para esa vista.

Las partidas guardadas se almacenan localmente en el navegador.
